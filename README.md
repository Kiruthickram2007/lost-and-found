# Findit — Lost & Found Portal

A responsive campus lost-and-found website for reporting items, searching records, filtering by type or category, and viewing item details.

## Features

- Submit lost or found item reports with contact and location details.
- Search reports by item name, category, location, and description.
- Filter the board by Lost, Found, and item category.
- Open item cards to see details and copy contact information.
- Keep newly submitted reports in browser local storage.
- Responsive layout for desktop and mobile.

## Run locally

1. Install Node.js (version 20.19+ or 22.12+).
2. Install dependencies with `npm install`.
3. Start the development server with `npm run dev`.
4. Open the local address printed in the terminal.

Use `npm run build` to create a production build and `npm run lint` to run Oxlint.

> Records are stored in the current browser only. Add a server and shared database before using this as a campus-wide service.
